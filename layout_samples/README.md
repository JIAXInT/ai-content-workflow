# 28 个版式骨架布局示例

本目录包含 guizang-social-card-skill 定义的 28 个版式骨架的**真正布局示例**，展示每个版式的实际结构和排版方式。

## 版式骨架列表

### Editorial Magazine × E-ink 系列（M系列）

| 编号 | 名称 | 适用场景 | 结构 |
|------|------|----------|------|
| M01 | Cover — 杂志封面 | 小红书首页、竖版社交卡片、文章封面 | 顶部期号栏 → 大号衬线标题 → 占页面35%-55%的大图 → 底部3-5个要点条带 |
| M02 | Field Note Photo — 田野笔记照片 | 户外、实物、硬件、真实世界观察记录 | 大幅纪实照片 → 窄幅说明列或底部说明带 → 大字短要点 |
| M03 | Editorial Essay Split — 编辑分栏随笔 | 用细节阐释单一观点 | 左侧大标题或引文 → 右侧2-3短段或编号片段 → 栏间细线分隔 |
| M04 | Pull Quote / Thesis — 引文/论点 | 核心句子或结论展示 | 跨页大引文 → 小字来源/上下文行 → 可选小注释或期号标记 |
| M05 | Checklist / Buying Guide — 清单/选购指南 | 小红书实用内容 | 标题头 → 4-6行（每行含编号、条目、结果说明）→ 可选小图或材质色块 |
| M06 | Evidence Wall — 证据墙 | 多张截图、参考文献或小图 | 2×2或3列图片网格 → 每图配短说明 → 一个较大标题锚定解读 |
| M07 | Closing Note — 收尾笔记 | 末页 | 大标题 → 4-6条账目项 → 收尾块（引文/签名/价格/CTA/旁注任选一）→ 小字页脚标签 |
| M08 | Tall Ledger — 高账目表 | 列表、角色、优劣对比、装备项、产品能力 | 标题头 → 4-6全宽行 → 左侧索引/旁注列，右侧标题+结果说明 |
| M09 | Atmospheric Thesis — 氛围论点 | 稀疏但重要的观点 | WebGL/墨流背景 → 大号论点或引文 → 1-2条支撑注释 → 小字期号元数据 |
| M10 | Evidence Feature — 证据专题 | 提供的截图/照片 | 占垂直画布45%-65%的大图 → 标题和导语在上方或旁边 → 底部说明带含2-3个要点 |
| M11 | Marginalia Essay — 旁注随笔 | 中等文字量的细致解释 | 宽编辑标题 → 主栏2-3段 → 窄旁注栏（关键词/引文片段/小图裁剪）→ 栏间竖向细线 |
| M12 | Section Divider — 章节分隔页 | 多页集中密集页面间的呼吸 | WebGL墨流背景 → 单行mono踢脚线 → 大号衬线章节标题 → 短副标题 |
| M13 | Hero Question — 核心问题 | 小红书多页集的最后一页 | WebGL墨流背景 → 安静踢脚线 → 大号衬线问题 → 单句提示引导评论 |
| M14 | Vertical Pipeline — 竖向流水线 | 3-5步工作流、决策树、配方 | 踢脚线+大标题 → 3-5个步骤行 → 步骤间细线 |
| M15 | Before / After — 前后对比 | 旧方式vs新方式、AI前vs AI后 | 踢脚线+大标题 → 两个对比块（Before块淡化，After块正常）→ 每块含独立要点 |
| M16 | Image-Led Cover — 图片主导封面 | 生活方式、图片密集内容 | 照片铺满画布 → 标题以克制方式覆盖其上 |

### Swiss International 系列（S系列）

| 编号 | 名称 | 适用场景 | 结构 |
|------|------|----------|------|
| S01 | Accent Cover — 强调色封面 | 小红书封面 | 全强调色或米白背景 → 大号轻量标题 → 简洁抽象系统块 → 底部元数据条带 |
| S02 | Two Signals / Comparison — 双信号/对比 | 两个来源、两个选项或两个产品方向的对比 | 页面标题 → 两个大矩形模块 → 各自下方短注 |
| S03 | Data Layer / File Card — 数据层/文件卡片 | Markdown、内存、数据源、数据库或状态展示 | 大型文件类型或对象块 → 3-4属性列表 → 粗mono标签 |
| S04 | Interface / Browser Mock — 界面/浏览器模型 | HTML、UI、演示、交互或输出层 | 直边浏览器窗口框架 → 内含一个主内容块+2-3功能模块 |
| S05 | Trap / Warning Rows — 陷阱/警告行 | 问题、反模式和不要这样做的页面 | 大警告标题 → 三横行 → 左mono标签，右结果说明 |
| S06 | Pipeline / Architecture — 流水线/架构 | 工作流和分层系统 | 三行或三列 → 每个含编号、标签、动作和结果 → 细线框和中性灰填充 |
| S07 | Takeaway Ledger — 收获账目 | 末页 | 大论点标题 → 三行账目 → 深色/墨色背景可创造收束感 |
| S08 | Image Hero — 图片主视觉 | 微信21:9主封面及小红书封面 | 顶部单行分类+日期 → 图片网格 → 底部3个统计块 |
| S09 | KPI Tower — KPI塔 | 产品更新、发布说明、流量仪表盘 | 踢脚线+大标题 → 4个塔列 → 一列可带muted修饰作为基线对比 |
| S10 | H-Bar Chart — 水平条形图 | 排名、5-10项对比、Top N列表 | 踢脚线+大标题 → 5-10条水平条形行 |
| S11 | Stacked Ledger — 堆叠账目 | 购物清单、支出汇总、Agent能力清单 | 踢脚线+大标题 → 4-6条账目行 |
| S12 | Matrix + Hero Stat — 矩阵+主数据 | 能力矩阵、Agent清单 | 踢脚线+大标题 → 8-12格矩阵 → 底部统计区 |

## 使用建议

1. **选择版式**：根据内容类型和场景选择合适的版式
2. **参考结构**：参考每个版式的结构说明进行布局
3. **调整细节**：根据实际内容调整字号、间距、颜色等细节
4. **保持一致**：在同一组图文中保持视觉风格的一致性
