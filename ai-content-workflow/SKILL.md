# AI 内容创作工作流

这是一个完整的 AI 内容账号每日创作工作流，覆盖公众号、小红书、抖音三端内容生产。

## 工作流程

### 第一步：获取 AI 热点

当用户说「今日热点」「AI 日报」「看看今天有什么」时：

1. 使用 `aihot` 技能获取最新 AI 热点精选
2. 按以下分类展示：
   - 🤖 模型发布
   - 🚀 产品发布
   - 📊 行业动态
   - 📄 论文研究
   - 💡 技巧与观点
3. 每条热点包含：标题、摘要、来源
4. 等待用户确认要写的选题

### 第二步：确认选题

用户从热点列表中选择 1-3 个感兴趣的选题，支持以下方式：

- 直接说编号：「写第 3 条」
- 说方向：「写那个模型发布的」
- 组合多条：「把 1 和 5 合在一起写」
- 自定义：「我想写关于 XX 的」

### 第三步：生成公众号文章

用户确认选题后，使用 `khazix-writer` 技能生成公众号长文：

1. **风格定位**：以「数字生命卡兹克」风格写作
   - 深度解读，不只是新闻搬运
   - 有观点、有态度、有洞察
   - 通俗易懂，接地气

2. **文章规格**：
   - 字数：4000-8000 字
   - 结构：引言 → 核心内容 → 深度分析 → 总结展望
   - 配图建议：3-5 处

3. **四层自检体系**：
   - **L1 硬性规则**：字数、格式、必含元素
   - **L2 风格一致性**：语言风格、人称、语气
   - **L3 内容质量**：信息密度、逻辑连贯、价值输出
   - **L4 活人感**：口语化、互动感、真实感

4. **输出文件**：
   - 文章文件：`{date}_{title}.md`（Markdown 格式）
   - 封面图：`cover.html` + `cover-square.html`
   - 质检报告：包含在文章末尾或单独文件

#### 自动生成封面图

在生成文章的同时，**自动生成公众号封面图**：

1. **封面规格**：
   - 公众号封面：900×383 像素（横版）
   - 朋友圈封面：383×383 像素（正方形）

2. **封面内容**：
   - 品牌标识：「AI创享派」+ 蓝色图标
   - 分类标签：AI 热点
   - 主标题：文章核心标题（精简版，15字以内）
   - 副标题：关键数据或亮点
   - 日期：发布日期
   - 底部装饰：蓝橙渐变条

3. **设计风格**：
   - 配色：莫兰迪色系（雾霾蓝 #6B8FAD + 奶茶棕 #C4A882）
   - 背景：米白 #F5F0EB + 几何装饰
   - 字体：Noto Sans SC + Inter
   - 风格：清爽科技、高级感

4. **生成流程**：
   - 使用 `frontend-design` skill 生成封面 HTML
   - 根据文章标题自动填充内容
   - 保存为 `cover.html` 和 `cover-square.html`
   - 可通过浏览器打开预览或截图

### 第四步：多端适配（可选）

根据用户需求，生成多平台内容：

#### 公众号
- 完整长文（4000-8000 字）
- 标题：2-3 个备选
- 摘要：100 字以内

#### 小红书
- 核心观点：3-5 个要点
- 正文：500-800 字
- 配图文案：每张图的描述
- 标签：5-8 个相关话题

#### 抖音
- 口播脚本：300-500 字
- 时长建议：60-90 秒
- 分段提示：哪里停顿、哪里强调
- BGM 建议

## 快捷命令

| 命令 | 功能 |
|------|------|
| `今日热点` / `AI 日报` | 拉取最新热点 |
| `写文章` | 基于已选热点生成公众号文章 |
| `质检` | 对已写文章跑四层自检 |
| `小红书` | 生成小红书版本 |
| `抖音` | 生成抖音口播脚本 |
| `全套` | 生成三端完整内容 |

## 注意事项

1. **热点时效性**：优先选择 24 小时内的热点
2. **选题建议**：优先选择有深度、有争议性、有讨论价值的话题
3. **标题党适度**：吸引眼球但不低俗
4. **原创观点**：必须有自己的分析和见解，不能只是搬运
5. **数据支撑**：尽量引用具体数据、案例
6. **互动设计**：文末设置互动话题，引导评论
